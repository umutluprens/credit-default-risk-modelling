# Data

Download `cs-training.csv` from Kaggle's **Give Me Some Credit** competition and place it in `data/raw/`.

Expected fields after normalisation:

| Field | Meaning |
| --- | --- |
| `serious_dlqin_2yrs` | Target: serious delinquency within two years |
| `revolving_utilization` | Revolving utilisation of unsecured lines |
| `age` | Borrower age |
| `past_due_30_59` | Number of 30-59 day delinquency events |
| `debt_ratio` | Debt ratio |
| `monthly_income` | Monthly income |
| `open_credit_lines` | Open credit lines and loans |
| `past_due_90` | Number of 90+ day delinquency events |
| `real_estate_loans` | Real-estate loans or lines |
| `past_due_60_89` | Number of 60-89 day delinquency events |
| `dependents` | Number of dependants |

Raw data and generated results are excluded from version control.
